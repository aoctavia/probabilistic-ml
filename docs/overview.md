# Project Overview

A self-contained technical explanation of what this project does, why each
part exists, and what a reviewer should take away from it.

---

## 1. The problem

Spatial transcriptomics technologies (e.g. 10x Genomics Visium) measure the
expression of tens of thousands of genes simultaneously across thousands of
tissue locations, each with known spatial coordinates. A typical dataset is a
matrix $X \in \mathbb{R}^{N \times D}$ with $N \approx 3{,}000$ spatial spots
and $D \approx 20{,}000$ genes — high-dimensional, structured, and noisy.

The biological question is: **which genes act together as co-expression
programmes, and where in the tissue is each programme active?**

This is an unsupervised learning problem: there are no labels, no ground truth,
and the answer must be inferred from the data alone. The spatial coordinates
carry information that a non-spatial model cannot use.

---

## 2. Factor models — the core idea

The working assumption is that the data have **low-dimensional latent structure**.
High-dimensional observations are approximately generated by a small number $K$
of latent factors:

$$X \approx Z W^\top$$

where:

- $Z \in \mathbb{R}^{N \times K}$ — **factor scores**: how strongly each programme
  is active at each spot
- $W \in \mathbb{R}^{D \times K}$ — **factor loadings**: which genes participate
  in each programme
- $K \ll D$ — the number of programmes is much smaller than the number of genes

With $K = 5$, for example, the model claims that five gene programmes explain
most of the variation in 20,000-dimensional data. Column $W_k$ lists the genes
involved in programme $k$; row $Z_i$ describes how active each programme is at
spot $i$.

Classical PCA finds the best rank-$K$ approximation. What this project builds is
the **probabilistic, structured, and spatially-aware** version of that idea.

---

## 3. Why probabilistic?

A deterministic model (standard PCA) returns a single point estimate. A
probabilistic model returns a **posterior distribution** over the latent
quantities — this matters for three reasons:

1. **Uncertainty quantification.** Are factor 2 and factor 3 genuinely distinct
   programmes, or are they noise? A posterior that is wide over the two factors
   says: the data do not distinguish them. A point estimate cannot say this.

2. **Model evidence.** The ELBO (derived below) provides a lower bound on the
   log marginal likelihood, enabling model comparison — e.g., choosing $K$.

3. **Structural priors.** The probabilistic framework allows encoding domain
   knowledge directly in the prior. The key prior in this project places a
   **Gaussian process** on the spatial factor scores, enforcing that nearby
   spots have similar latent representations.

---

## 4. The model hierarchy

### M0 — Baseline (Probabilistic PCA)

$$z_i \sim \mathcal{N}(0, I_K), \qquad
w_j \sim \mathcal{N}(0, I_K), \qquad
\tau \sim \text{Gamma}(a_0, b_0)$$

$$x_i \mid z_i, W, \tau \sim \mathcal{N}(W z_i,\; \tau^{-1} I_D)$$

Observations are treated as **exchangeable** — no spatial structure. This is the
reference point: every other model is compared against it.

### M1 — Sparse loadings

A sparsity-inducing prior (horseshoe or spike-and-slab) on $W$. Most entries of
$W$ are shrunk toward zero; only a few genes load strongly on each factor. This
makes the factors interpretable as gene programmes with a small signature.

### M2 — Automatic relevance determination (ARD)

An ARD prior on the columns of $W$ with per-factor precision parameters
$\alpha_k$. Factors with low signal are driven to zero automatically, so the
effective $K$ is inferred from data rather than fixed.

### M3 — Spatial factor model *(core contribution of this branch)*

The prior on $Z$ is replaced by independent Gaussian processes, one per factor:

$$z_{\cdot k} \mid \theta_k \sim \mathcal{GP}(0,\; \kappa_{\theta_k}), \qquad k = 1, \dots, K$$

where $\kappa_{\theta_k}$ is the squared-exponential kernel:

$$\kappa(s_i, s_j) = \alpha_k^2 \exp\!\left(-\frac{\|s_i - s_j\|^2}{2\ell_k^2}\right)$$

Each factor has its own amplitude $\alpha_k$ and lengthscale $\ell_k$, allowing
factors to operate at different spatial scales. The observation model and loading
prior are unchanged from M0.

**Interpretation:** $\ell_k$ small means programme $k$ is active only in a
narrow tissue domain; $\ell_k$ large means it is expressed diffusely across the
whole section.

### M4 — Multi-view

Multiple data matrices $X^{(m)}$ share the same latent factors $Z$, with
view-specific loadings $W^{(m)}$ and noise precisions $\tau_m$. ARD controls
which factors are active in each view. This is the MOFA-style model
(Argelaguet et al., 2020).

## 5. Inference — CAVI

### The variational problem

The posterior $p(Z, W, \tau \mid X)$ is intractable. Variational inference
approximates it with a tractable distribution $q(Z, W, \tau)$ by maximising
the **ELBO**:

$$\mathcal{L} = \mathbb{E}_q[\log p(X, Z, W, \tau)] - \mathbb{E}_q[\log q(Z, W, \tau)]$$

$\mathcal{L}$ is a lower bound on $\log p(X)$: the tighter the bound, the
closer $q$ is to the true posterior. Maximising $\mathcal{L}$ is equivalent to
minimising $\text{KL}(q \| p)$.

### Mean-field assumption

We adopt the fully factorised (mean-field) family:

$$q(Z, W, \tau) = q(Z)\, q(W)\, q(\tau)$$

This discards posterior correlations between $Z$ and $W$. The cost of this
approximation is measured empirically in the calibration experiment (E4).

### Coordinate ascent

Because M0 has conjugate priors, the optimal factor for each variable — the one
that maximises $\mathcal{L}$ with all others fixed — has a closed form:

| Variable | Optimal $q^*$ | Key quantity |
|----------|---------------|--------------|
| $z_i$ | $\mathcal{N}(m_i, S_Z)$ | $S_Z = (\mathbb{E}[\tau]\,\mathbb{E}[W^\top W] + I_K)^{-1}$ |
| $w_j$ | $\mathcal{N}(\mu_j, S_W)$ | $S_W = (\mathbb{E}[\tau]\,\mathbb{E}[Z^\top Z] + I_K)^{-1}$ |
| $\tau$ | $\text{Gamma}(a_N, b_N)$ | $b_N = b_0 + \frac{1}{2}\mathbb{E}[\|X - ZW^\top\|_F^2]$ |

Crucially, all $z_i$ share the **same covariance** $S_Z$ — it depends on $i$
only through the mean $m_i$. This reduces storage from $\mathcal{O}(NK^2)$ to
$\mathcal{O}(NK + K^2)$.

### ELBO decomposition

$$\mathcal{L} = \underbrace{\mathbb{E}[\log p(X \mid Z, W, \tau)]}_{T_\text{lik}}
- \underbrace{\text{KL}(q(Z) \| p(Z))}_{T_Z}
- \underbrace{\text{KL}(q(W) \| p(W))}_{T_W}
- \underbrace{\text{KL}(q(\tau) \| p(\tau))}_{T_\tau}$$

Each term is analytic. $T_Z$ and $T_W$ are KL divergences between Gaussians;
$T_\tau$ is the KL between Gamma distributions.

### Correctness gate

The ELBO is **guaranteed to be non-decreasing** across iterations by
construction — each coordinate update is a maximisation step. This property is
verified in `tests/test_cavi.py::TestELBOMonotonicity`. Any violation signals
a bug in the update equations.

## 6. Identifiability — the central theoretical problem

### The invariance

Factor models are invariant to any invertible matrix $R \in \mathbb{R}^{K \times K}$:

$$ZW^\top = (ZR^{-1})(WR^\top)^\top$$

This creates three classes of non-identifiability:

1. **Rotational invariance** — any orthogonal $R$ leaves the likelihood unchanged
2. **Column permutation** — factor ordering is arbitrary
3. **Sign flips** — negating column $k$ of $Z$ and $W$ simultaneously

### Why this matters in practice

Under an uninformative prior, the posterior over $(Z, W)$ is a mixture of
equivalent modes related by these transformations. If you run MCMC and
naively average the samples, each sample may represent a different rotation:
the average converges to zero and the signal is destroyed.

This is not a theoretical curiosity — it is a practical failure mode that
invalidates any posterior summary computed without first aligning the samples.

### How structural priors partially resolve it

Sparsity priors on $W$ (M1) **partially** break rotational invariance: there
is no rotation that simultaneously keeps all columns sparse. The word
"partially" is important — the posterior geometry is constrained but not
uniquely determined.

Column ordering can be fixed by ordering factors by decreasing explained
variance. Sign ambiguity can be fixed by a positivity constraint on the
first loading of each factor.

### Post-hoc alignment

For MCMC posteriors, alignment is required before computing summaries:

1. Choose a reference sample (e.g. the posterior mode).
2. For each other sample, find the permutation + sign assignment that minimises
   Frobenius distance to the reference (Hungarian algorithm).
3. Apply orthogonal Procrustes alignment for the continuous rotational component.

Experiment E3 demonstrates this empirically: it shows MCMC output before
alignment (visually destroyed), after alignment (recoverable), and quantifies
what alignment fixes and what it does not.

## 7. Inference for M3 — SVI

### Why CAVI breaks for M3

The analytic CAVI update for $q(Z)$ in M0 exploits the fact that the prior on
each $z_i$ is an isotropic Gaussian, which makes the precision of $q(z_i)$
independent of $i$. With a GP prior, the prior covariance of $z_{\cdot k}$ is
the full $N \times N$ Gram matrix $K_k$ — the precision of the variational
distribution is no longer shared across spots and there is no closed-form
coordinate update.

### Stochastic variational inference

We parameterise the variational distribution in unconstrained space (log-space
for positive quantities) and optimise the ELBO by gradient ascent using JAX's
automatic differentiation:

$$\theta^{(t+1)} = \theta^{(t)} + \eta \nabla_\theta \mathcal{L}(\theta^{(t)})$$

where $\theta$ is the flat vector of all variational parameters. The gradient is
computed via `jax.grad`; the optimiser is Adam.

### ELBO for M3

$$\mathcal{L}_{M3} = \mathbb{E}_q[\log p(X \mid Z, W, \tau)]
- \sum_{k=1}^K \text{KL}\!\left(\mathcal{N}(m_k, \text{diag}(v_k)) \| \mathcal{N}(0, K_k)\right)
- \text{KL}(q(W) \| p(W))
- \text{KL}(q(\tau) \| p(\tau))$$

The KL between two Gaussians is analytic:

$$\text{KL}(\mathcal{N}(m, \Sigma_q) \| \mathcal{N}(0, K))
= \frac{1}{2}\!\left(\operatorname{tr}(K^{-1}\Sigma_q) + m^\top K^{-1} m
- N + \log\det K - \log\det \Sigma_q\right)$$

We compute $K^{-1}$ and $\log\det K$ via Cholesky decomposition for numerical
stability.

### Computational bottleneck and sparse approximation

Naively, forming $K_k$ and computing its Cholesky costs $\mathcal{O}(N^2)$ and
$\mathcal{O}(N^3)$ respectively. For $N \sim 10^4$ spots (full Visium), this is
infeasible.

The remedy is an **inducing-point (sparse GP) approximation**: choose $M \ll N$
inducing locations, approximate the GP with a rank-$M$ structure, and reduce
the per-step cost to $\mathcal{O}(NM^2)$.

## 8. Experiments — what each one tests

### E1 — Recovery under known truth

Simulate data from M0 where the true $Z, W, \tau$ are known. Sweep over
$N$, $D$, $K$, and $\tau$. Measure recovery with two rotation-invariant metrics:

- **Subspace distance** (Grassmann distance): how far the estimated factor
  subspace is from the true one
- **Matched correlation**: mean absolute Pearson correlation after optimal
  column matching (Hungarian algorithm)

Deliverable: a phase diagram showing where M0-CAVI recovers structure and where
it fails.

*Current finding:* recovery improves with $D$ and moderately with $N$; degrades
gracefully with $K$. At high SNR ($\tau = 10$), CAVI does not converge within
500 iterations despite a good subspace distance of 0.09 — evidence of slow
mixing near the optimum at high noise precision.

### E2 — Misspecification

Generate data that violates the model's assumptions: heavy-tailed noise,
non-smooth spatial structure, a misspecified $K$. Show how each model variant
degrades. A model that fails gracefully is a finding; a model that fails
silently is a more important finding.

### E3 — Identifiability

Empirical demonstration of the three invariances using MCMC output.
Show that naive posterior means over unaligned samples are near zero.
Apply post-hoc alignment and show recovery. Quantify what alignment fixes
and what it cannot fix. Verify the claim that sparsity priors partially
constrain the posterior geometry.

### E4 — Calibration

Simulation-based calibration (SBC) for the MCMC implementation.
Posterior coverage curves for VI variants: do nominal 50/80/95% intervals
contain the true value that fraction of the time? Mean-field VI is expected
to be overconfident — E4 quantifies by how much.

### E5 — Scaling

Wall-clock time and peak memory versus $N$, $D$, $K$ for each inference
method on fixed hardware. Report the crossover point where MCMC becomes
infeasible and SVI is the only option.

### E6 — Real data (Visium)

A single public spatial transcriptomics dataset (10x Genomics Visium).
Fit M3, display the spatial factor maps (where each programme is active in the
tissue), and show the uncertainty. State explicitly what cannot be concluded
without domain expertise. The goal is an honest analysis, not a biological
discovery.

## 10. Engineering choices and why they matter

**JAX as the backend.** JAX provides `jit` (just-in-time compilation),
`grad` (automatic differentiation), and explicit PRNG key management. The
explicit key threading — every random call takes a key argument, no global
state — makes experiments fully reproducible from a seed without hidden
randomness.

**Typed, linted, tested.** `mypy --strict`, `ruff`, and a test suite with
correctness gates (ELBO monotonicity, gradient check) make the implementation
auditable. A reviewer can run `make check` and `make test` and verify the
claims in the documentation without reading every line of code.

**Derivation before implementation.** Every model and inference update is
derived in `docs/methods.md` before the corresponding code is written. The
document and the code are two presentations of the same mathematics.

**Honest failure documentation.** Negative results from experiments are
reported as findings, not tuned away. `docs/limitations.md` exists and is
specific.
